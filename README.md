# 🪙 Gold Oracle

> A Python-based data analytics and machine learning application designed for tracking, analyzing, and forecasting gold price trajectories using historical market data, tax adjustments, and linear regression modeling.
> 🌟 Key Features
Market Data Integration: Automatically fetches historical and live commodity market datasets using yfinance and requests.

Predictive ML Modeling: Implements linear regression models via scikit-learn to forecast future commodity price movements.

Tax & Cost Adjustments: Computes localized pricing impacts by factoring in import duties, taxes, and handling fees.

Data Visualization: Generates clean trend charts and correlation heatmaps utilizing matplotlib and seaborn.

Interactive UI: Powered by Streamlit to let users adjust parameters and view live forecasting charts instantly.
